
# Parquímetro em JavaScript

Projeto desenvolvido durante o curso de Front-End da EBAC, com o objetivo de simular o funcionamento de um parquímetro utilizando JavaScript.

## Sobre o projeto

A aplicação permite que o usuário informe um valor e, a partir dele, calcula o tempo de permanência e o troco, caso necessário.

### Tabela de valores

| Valor | Tempo |
| --- | --- |
| R$ 1,00 | 30 minutos |
| R$ 1,75 | 60 minutos |
| R$ 3,00 | 120 minutos |

Caso o valor informado seja inferior a R$ 1,00, a aplicação apresenta uma mensagem de valor insuficiente.

## Módulo 7 - Programação Orientada a Objetos

Desenvolvimento inicial da aplicação utilizando classes, atributos e métodos em JavaScript.

## Módulo 8 - Refatoração e modularização

Neste módulo, reorganizei o código desenvolvido anteriormente, mantendo as funcionalidades e o layout original da aplicação.

Principais alterações:

- Separação do JavaScript em módulos;
- Utilização de import e export;
- Aplicação dos métodos map(), find() e reduce();
- Criação de funções auxiliares;
- Utilização de addEventListener();
- Manipulação dinâmica do DOM.

## Organização dos arquivos

- index.html: estrutura da aplicação.
- style.css: estilização da página.
- js/classes.js: definição da classe Parquimetro.
- js/utils.js: funções auxiliares e cálculos.
- js/app.js: integração dos módulos e manipulação do DOM.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)

## Como executar

Clone o repositório e execute o arquivo index.html utilizando a extensão Live Server no VS Code.
